# Phase 4 Connected-Demo Pre-Enable Checklist

This checklist deliberately stops before demo order execution is enabled.
Complete it with `EnableDemoExecution=false`, `ApprovedDemoAccount=0`, and
`AllowLiveTrading=false`.

## 1. Install the exact Phase 4 source

With MetaTrader closed or the EA removed from all charts, copy:

```text
repository/MQL5/Experts/SolTradeBot.mq5
    -> terminal-data/MQL5/Experts/SolTradeBot.mq5

repository/MQL5/Include/SolTrade/*
    -> terminal-data/MQL5/Include/SolTrade/*

repository/MQL5/Scripts/SolTradeRiskTests.mq5
repository/MQL5/Scripts/SolTradeStrategyTests.mq5
repository/MQL5/Scripts/SolTradeExecutionTests.mq5
    -> terminal-data/MQL5/Scripts/
```

The `SolTrade` include folder must contain:

```text
AccountGuard.mqh
Config.mqh
Dashboard.mqh
ExecutionEngine.mqh
MarketData.mqh
RiskEngine.mqh
StrategyBreakout.mqh
TradeJournal.mqh
```

Do not copy an older `SolTradeBot.ex5` over the newly compiled file.

## 2. Compile without enabling execution

Open and compile these files individually in MetaEditor:

1. `MQL5/Experts/SolTradeBot.mq5`
2. `MQL5/Scripts/SolTradeRiskTests.mq5`
3. `MQL5/Scripts/SolTradeStrategyTests.mq5`
4. `MQL5/Scripts/SolTradeExecutionTests.mq5`

Each Toolbox result must be:

```text
0 errors, 0 warnings
```

Confirm these files now exist and have a current modification time:

```text
MQL5/Experts/SolTradeBot.ex5
MQL5/Scripts/SolTradeRiskTests.ex5
MQL5/Scripts/SolTradeStrategyTests.ex5
MQL5/Scripts/SolTradeExecutionTests.ex5
```

## 3. Run deterministic tests only

Keep the EA detached. The execution test script constructs requests and
persistent-state fixtures but never calls the broker submission path.

Run `SolTradeExecutionTests` once from Navigator → Scripts. Require:

```text
SolTrade Execution tests complete: 74 passed, 0 failed
ALL SOLTRADE PHASE 4 EXECUTION TESTS PASSED
```

Also retain the previously approved results:

```text
ALL SOLTRADE PHASE 2 RISK TESTS PASSED
ALL SOLTRADE PHASE 3 STRATEGY TESTS PASSED
```

Any failed test is a stop condition. Do not enable demo execution.

## 4. Attach in locked monitoring mode

Open the broker's EURUSD symbol on H1. A suffix such as `EURUSD.` is acceptable
only when `TradeSymbol` exactly matches it and still begins with `EURUSD`.

Attach `SolTradeBot` with:

```text
ExpectedEnvironment    = AUTO_DETECT or DEMO
EnableDemoExecution    = false
ApprovedDemoAccount    = 0
AllowLiveTrading       = false
EmergencyStop          = false
RiskPerTradePercent    = 0.25
MaxSpreadPoints        = 30
MaxSpreadAtrPercent    = 10.0
MagicNumber            = 2607202601
```

The Algo Trading button may remain off for this pre-enable stage. With it on or
off, `EnableDemoExecution=false` must remain the controlling refusal.

## 5. Confirm the locked dashboard

On an easyMarkets demo account, require:

```text
Account mode: DEMO
Status: DEMO EXECUTION DISABLED
Build scope: ENTRY EXECUTION ONLY - PHASE 4; NO STRATEGY EXITS
Demo execution enabled: NO
Execution environment eligible: NO
Execution state valid: YES
Open SolTrade positions: 0
Active SolTrade orders: 0
Conflicting symbol positions: 0
Unprotected SolTrade position detected: NO
Risk per trade: 0.25%
```

The signal, EMA 200, Donchian 20/10, ATR 14, and initial stop distance should
continue to display after the next completed H1 candle.

Confirm in Trade/Exposure and History that no order, deal, or position was
created.

## 6. Confirm journal and persistent state

From MetaTrader, use File → Open Data Folder. Check:

```text
MQL5/Files/SolTradeBot/logs/
MQL5/Files/SolTradeBot/state/
```

In Strategy Tester, the equivalent files may be under the tester agent's
`MQL5/Files` sandbox.

The CSV should contain:

```text
EXECUTION_STATE_INITIALISED or EXECUTION_STATE_RESTORED
FOUNDATION_STARTED
ACCOUNT_GUARD_REFUSAL
```

The refusal must state:

```text
EnableDemoExecution is false
```

If a BUY or SELL signal occurs while locked, require an
`EXECUTION_REJECTED` row with:

```text
reason_code=DEMO_EXECUTION_DISABLED
retry_allowed=NO
```

No log may contain the raw account login.

The execution state filename is scoped by the account hash and magic number:

```text
execution_<account-hash>_<magic-number>.csv
```

Do not edit this file.

## 7. Restart while still locked

Before the next H1 boundary:

1. Leave `EnableDemoExecution=false`.
2. Remove and reattach the EA, or restart MetaTrader.
3. Confirm `EXECUTION_STATE_RESTORED`.
4. Confirm the dashboard still shows zero SolTrade positions/orders.
5. Confirm the previously completed candle does not produce a submission.
6. Confirm no order, deal, or position appears.

A checksum/schema/state restoration error is a stop condition.

## 8. Capture evidence and stop

Export or capture:

- all four MetaEditor compile summaries;
- the complete Phase 4 script output showing `74 passed, 0 failed`;
- the locked dashboard;
- Trade/Exposure and History showing no new activity;
- the relevant Experts and Journal lines;
- the CSV header and Phase 4 startup/refusal rows;
- the execution-state restoration row after restart;
- the demo account login separately for later approval configuration (do not
  include it in public logs or screenshots).

Do not yet set `EnableDemoExecution=true`, do not enter
`ApprovedDemoAccount`, and do not perform a demo entry. Review this evidence
before the first controlled demo-execution test.
