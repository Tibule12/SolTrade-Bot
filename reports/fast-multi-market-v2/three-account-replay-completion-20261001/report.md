[FP 24-hour receipt](fp-24h-export/export-receipt.json) · [native-bar receipt](native-opposite/bar-export/export-receipt.json).

**Permission exception:** the isolated 10K startup file set `AllowLiveTrading=0`, but the EA's runtime log reported `MQL_TRADE_ALLOWED=1` and `TERMINAL_TRADE_ALLOWED=1`. That fails the requested *no trading permissions* condition, even though this specific program has no order API and no new broker deal appeared. The research terminal was closed; no 100K or additional FXIFY probe was run after this finding. MT5's [official startup reference](https://www.metatrader5.com/en/terminal/help/start_advanced/start) says `AllowLiveTrading=0` should disable EA trading, so the discrepancy needs a verified read-only login or a proven terminal-level fix before any further account access. The exact startup and runtime values are preserved in the [10K receipt](fxify-10k-broker-export/recovery-receipt.json).
